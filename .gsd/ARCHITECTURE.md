## Overview

Passage is a Windows-native desktop application for screenwriting, using the Fountain markdown language format. It parses plain-text screenplays formatted in Fountain syntax, estimates pagination, tracks goals (word count, page count, session timers), and exports screenplays to industry-standard PDF layout formats.

## Data Flow

1. **User loads or types screenplay:** Text is fed into the WPF Editor (`MainWindowViewModel`).
2. **Parsing & Estimation:** `FountainParser` processes the text into a `ParsedScreenplay` containing screenplay elements (`DialogueElement`, `SceneHeadingElement`, etc.).
3. **Goal Tracking:** The parsed screenplay is passed to `GoalProgressCalculator` and `ScreenplayPageEstimator` to compute word counts, estimated page counts, and compare them against targets.
4. **Export (Optional):** When exporting to PDF, `ScreenplayLayoutBuilder` processes elements, breaking them into physical page-height layout runs, and `ScreenplayPdfExporter` writes standard PDF binary files to disk.
